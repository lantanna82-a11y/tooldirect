# Мастерская знаний

Статическое Telegram Mini App, которое вручную собирается из заметок Obsidian.

## Сборка

1. Положите исходные заметки в соседнюю папку `1`.
2. Выполните `npm run check`.
3. Готовый сайт появится в `dist`.

Основная структура берётся из `1/Деревообработка`. Уникальные дополнительные статьи добавляются после проверки дублей. Исходные заметки не изменяются.

Сборщик выполняет:

- построение разделов по главному оглавлению;
- преобразование Markdown, wikilinks, тегов, таблиц и callout-блоков;
- очистку текста, метаданных и SVG;
- создание поискового индекса;
- генерацию SVG-черновиков для процессов, сравнений и размерных данных;
- подготовку полностью статического сайта без сервера и базы данных.

## Ручное обновление

После изменения заметок запустите локально `npm run check`, просмотрите `dist/index.html`, затем отправьте папку `knowledge-mini-app` в ветку `main`. Исходные заметки не загружаются. Workflow повторно проверит и опубликует уже очищенный каталог `dist` на GitHub Pages.

В настройках репозитория выберите `Settings → Pages → Source → GitHub Actions`.
